**不能将官方坐标盒直接宣称等于两个范数球，也不能靠缩小盒或求解后强行投影制造其失败。**

执行要求：

### B2. 直接同合同SQP

使用现有SciPy SLSQP，不重新实现SQP，单一启动值为实际previous_q。

令 `y=S^-1(q-previous_q)`，求：
`min 0.5*||y||²`
subject to：
`1-||e_p(q)||² >= 0`
`1-||e_R(q)||² >= 0`
及原当前帧动态关节箱。

提供目标与两个约束的解析导数，姿态导数沿用已核对的SO(3)定义；同配置FK/Jacobian缓存。
初始使用 `maxiter=100, ftol=1e-8` 与相同20 ms外层软期限。这里100不是保证运行100步，而是在共同时间内不人为给参照过少迭代。需要修正数值设置时只在270-query开发集上进行，最多3个事先声明的合理设置。

一旦已计算的候选通过原verifier，就缓存并结束，不强迫它继续求最小位移最优解。必须明确标记 `task_accepted_early`，不把它宣称为SQP目标最优。

所有候选只能来自该调用自己的迭代，不读取witness、其他方法输出、参考路径或额外seed。真实超时原样记录，不能裁掉实际耗时。主方法不调用这个对照。

### B3 / B4. 同核固定1次、2次局部加权QP

名称：`fixed_qp1`、`fixed_qp2`。
它们与当前minimax方法保持相同目标、首个θ、外层更新、阻尼、回溯、状态反馈、缓存、命令验收与总时间上限。

唯一区别：每个局部子问题最多求解K个加权箱QP，K=1或2；K指局部加权QP调用，不是活动集内部更新数，也不是整个IK只能迭代一两次。

- 已有合法命令可以提前返回；精确端点/平衡已判定时不强迫无用地凑满K。
- 达到K但未得到合法命令，返回迄今最小局部原始目标的箱内方向，继续相同外层过程，不故意使该方法直接失败。
- 不计算其运行本来不需要的forcing下界或gap，避免把额外检查成本强加给简单对照。
- 为选择第二次θ所需的同一对偶导数/括区步骤仍保留；只取消相对进展停止规则。
- 真实非线性目标未下降时仍按原外层处理，不放宽验收或容许无限预算。
- 对照的gap、模型下降率如需报告，在离线诊断中计算，不混入在线计时。

可以提取一个薄的局部函数副本并保留明确diff，或使用实例级回调；不得全局替换主方法，也不层层继承旧运行器。

## 5. 一个应用来源：验证场景意义，不扩大成新机器人系统

先用仓库现有文件查找真实的Cartesian任务日志、规划器路径或任务几何。不得把原FK随机关节轨迹改个名字称作工业应用。

只选择一个任务类别。优先使用已有真实记录；没有可用记录时，使用一个明确标注为“应用型合成验证”的非接触扫描/观测位姿序列。RangedIK的相机运动实例可作为动机来源，不能伪称复现了其硬件实验。

执行前写一页任务定义并固定输入：
- 位姿目标来自哪份记录，或扫描平面/观察点、工位变换和时间参数；
- 位置/姿态容差来自任务要求，还是沿用本研究的1mm/0.5°软件假设；后者不得伪称真实工业公差；
- 目标由Cartesian任务几何定义，不从被测solver成功轨迹反向生成；
- 速度与节拍依据先定，不为了制造GN失败推到最大关节利用率；
- 所有方法只见当前和历史目标，使用相同起点和时间索引。

范围上限：每机器人12条完整序列、每条150帧；现成记录长度不同可以保留原段，但不得按新方法成功选段。全部输入必须在任何方法运行前固定。只做一个任务，不混入接触、碰撞、视觉网络或新硬件控制。

应用方法保留：`relative, gn, direct_sqp, 范围参照, fixed_qp1, fixed_qp2`。不需要重跑全部历史solver。

每方法3遍。每条从第0帧运行：接受才反馈；失败保持；目标继续推进；所有帧计时。仍按原运动学执行语义统计，不假装硬件真实时间执行。

报告TSR、DTSR20、帧接受率、累计时间、误差、加速度及失败位置，附一幅实际轨迹图。只用真实数据作图。

应用数据不必被强制做成每帧已知可行。只有准确当前输入有独立合法witness时，才把某次失败称为已知可行漏解；没有witness则记为未返回合格命令。不得因某方法失败筛掉该段。
