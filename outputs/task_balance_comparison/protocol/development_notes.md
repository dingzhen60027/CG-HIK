# 开发冻结说明

运行环境：原isaaclab_3，NumPy fallback，CPU4、单线程。
20个新增测试与13个已有边界测试共33项通过；弃用告警来自现有hppfcl名称，未升级环境。
测试覆盖官方损失解析梯度、实际Panda/UR5e SO(3)及位置导数、两不等式梯度、
实例级回调不污染主方法、相同外层bytecode、固定QP预算计数、初始合法命令直接验收。

首次开发每机器人270×4×3调用。Panda：range_loss_matched 804/810、
fixed_qp1 804/810、fixed_qp2 810/810；UR5e分别795/810、801/810、810/810。
它们按预声明设置冻结，不以未恢复为由追加范围loss参数。

SQP首次开发Panda 0/810、UR5e 3/810，原生success多为微小不等式越界而任务拒绝。
在运行新设置前记录且只增加1e−7归一化平方约束内部裕量；没有改公共verifier或
主方法。第二次仅SQP开发，两机器人均810/810。原始记录与v1源码均保留。
没有按验证2160集选择设置，没有为不同机器人设置不同裕量。
开发第一次脚本执行曾有未配对括号语法错误，修复后才prepare，无任何求解记录受影响。

统计脚本将从两个开发版本的记录自动汇总完整时间、失败、误差，不以此文件的简数
替代证据。接下来先提交协议/代码/身份，然后运行主比较与应用。应用输入已固定，
其曲線来自Cartesian几何，不读取被测方法结果筛选或重生成。
