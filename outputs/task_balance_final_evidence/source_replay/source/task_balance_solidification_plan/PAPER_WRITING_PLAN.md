# Task Balance GN：证据补强后的论文写作计划

状态：待上述最后一轮证据完成并验收。本文件是写作安排，不是已完成稿件或录用保证。

## 1. 全文主线

位姿误差分别验收 + 有限关节运动
→ 固定误差折中可能遗漏合格命令
→ 任务均衡的有界局部更新
→ 利用双块结构并借鉴非精确求解原则控制计算
→ 受限查询中的覆盖—成本证据
→ 普通查询、连续反馈和真实来源回放界定适用范围。

论文身份：任务特定的增量数值IK方法。不是新优化理论、学习路由系统、路径规划器或实机控制性能论文。

建议标题：
**Task-Balanced Inexact Gauss–Newton for Rate-Constrained Inverse Kinematics**

标题不写“globally optimal”“universal”“real-world robust”“safety-certified”。

## 2. 先确定结果的身份与来源

现有证据必须保持原有身份，不将不同批次混成一个fresh test：
- 原普通点/轨迹：冻结的独立评价。
- 原任务集2160-query域：原协议固定的补充适用域验证。
- 最近八方法比较：在已观察共同输入上的补充比较。
- 新公开真实日志：锁定的公开子集上的离线再求解；不是新采集的实机试验。
- 新敏感性：已观察开发anchors上的有限条件试验。
- 旧合成扫描：应用型合成验证；未激活新机制的事实保留。

同一张性能表只用同批实测时间。以relative对tight/fixed2解释规则，以relative对GN解释整体方法差异；不能将缓存节省全部归为新停止机制。

## 3. 三个研究问题

RQ1：在位姿容差与速率边界同时起作用的查询中，任务均衡是否减少不合格折中？

RQ2：相较固定局部工作量、紧精度与通用约束优化，该数值组织是否提供更合理的覆盖—成本折中？

RQ3：这种作用依赖什么条件，在普通查询、连续运行、不同容差和真实来源输入中怎样表现？

RQ3可以是无增量或有条件作用。不要把它预设成一定提高整轨迹成功率。

## 4. 章节安排

### 1 Introduction

约6段，不写研发版本史：
1. Cartesian命令到关节命令的接口，有限运动与分项容差的实际含义。
2. 肯定已有数值IK、范围/集合任务、约束优化；问题不是“别人不处理约束”。
3. 明确点误差折中与同时验收的差别，用短例子或指向机制图。
4. 说明更合适的目标也可能引入不必要的局部高精度求解。
5. 引入一个统一Task Balance GN，不将成熟数学组件各自包装为创新模块。
6. 提出具体方法贡献和三个RQ。应用意义必须与实际回放结果一致。

### 2 Related Work

仅三条线：
- 数值IK与动态边界；
- 范围/集合任务和精度分配，重点RangedIK及set-based方法；
- 非精确复合优化及相对进展，包括2024年直接同型规则来源。

引用经过实际核验的原始文献。预印本标注身份；数量以相关性为准，不用无关学习论文凑35/40篇。

### 3 Problem Formulation

清楚定义输入、残差坐标系、两个容差球、固定于上一真实状态的动态箱、计算预算。
分开任务可接受性、已找到的witness、数值终止及按时返回。
给出一维解析例子作为解释，不能取代机器人实验；不把一般GN失败当作全局不可能。

### 4 Method

一个算法伪代码、一套符号：
局部双块minimax、标量对偶、θ=.5首步、任务提前接受、已有相对精度思想的具体使用、真实残差回溯、最终验收。

三项数学性质限于它们实际证明的范围，停止规则归属写在首次出现处。
对同点缓存、数值库、κ居中、活动集写实现说明，不单列创新。

### 5 Experimental Design

先写实验问题，再写数据集与对照，而不是罗列大量运行。
说明公共合同、输入权限、witness不作seed、软20ms deadline、计时/预热、聚类单位。
范围损失匹配参照不是完整RangedIK。真实数据的命令周期与20ms计算评价期限分开。

### 6 Results

6.1 受限查询覆盖与误差分配：原GN、固定权重和同目标参照；全样本及全部格。
6.2 计算分配：fixed1/fixed2/tight/Clarabel/SQP，配合QP工作量。
6.3 普通与连续运行：保留无新增完成及不利时延/平滑性。
6.4 真实来源回放与小型敏感性：只写真正测到的条件作用，不讲未执行的实机。

### 7 Discussion and Conclusion

讨论一个问题：在哪些约束/任务条件下值得采用这项额外的任务均衡？
归属、适用范围、实际应用未证明部分集中写，不在每段机械重复“不能声称”。
结论回到当前查询的覆盖—计算折中，不跳到全局路径与物理控制保证。

## 6. 写作次序与交付

验收后按以下顺序写，先结果后摘要：

1. 固定claim–evidence表、数据身份和主图表；完成Methods/Experimental Design。
2. 完成Results，逐段写清比较对象、方向、效应量及不确定性。
3. 写Introduction/Related Work，把已有贡献归属放准确。
4. 写Discussion/Conclusion，再写Abstract和标题。
5. 进行一次全文闭环审查：题目、摘要、贡献、公式、图表、结论是否指向同一问题。
6. 确认目标期刊和学校年度分区口径后再迁移模板、填写真实署名/声明；不由模型捏造。

计划量级：证据可读取后，正文整理约3—5个工作日的工作安排，不是自动执行或进度保证。

旧main.pdf仍是学习级联版本，归档为历史，不在其摘要后追加当前数值方法。新版从当前主线重组；旧失败研究不写成主文的版本流水账。

## 7. 结果决定主张，不决定是否继续无限做实验

- 真实来源中有增量且有限敏感性表现一致：在限定数据/任务要求下主张离线应用相关性。
- 真实来源没有触发：以受限查询数值方法为核心，回放用于说明常规负载的边界；不称实机应用优势。
- 某个敏感性条件明显退化：写入适用条件，不改主方法抹掉它。
- 真实日志访问或语义未解决：不得把缺失项说成完成；论文计划保留其待决身份，由用户决定是否继续收集。

这些结果不自动证明新颖性充分，更不保证录用。写作基于已确认的方法增量，不能用应用演示或新增工作量替代原创性论证。
