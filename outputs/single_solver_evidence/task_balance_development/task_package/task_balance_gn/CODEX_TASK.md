## 4. 主指标与增量归因

TSR、DTSR20保持原定义。辅助：
- 原始完整时延P50/P95/P99及累计时间；
- 接受命令max(normalized position, normalized orientation)>0.9的比例；
- 位置/姿态误差P95及最大值；
- 加速度RMS、失败和恢复UID；
- theta=0.5首步即返回比例，继续对偶求解比例及其实际恢复；
- 真实残差/Jacobian/验收次数，不能只数外层迭代。

“max误差更小”“贴边更少”不等于更安全或保证更好的闭环。
新κ1和原κ1比，新κ0和原κ0比；不能用κ1相对纯Phi κ0的差别
单独证明minimax目标的贡献。

本地发现：新κ1为40/40，κ0仍39/40；命令常与原GN极接近。
这些负面/中性事实必须保留。当前还没有整体完成增量证据。
本轮真正目标是：保留原GN正常帧与运动质量，同时兑现失败输入上的新恢复，
并控制而不是隐藏额外计算。
