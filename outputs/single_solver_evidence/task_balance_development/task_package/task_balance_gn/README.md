# 位置—姿态容差均衡 GN：本地开发原型与结果

## 目的

继续同一研究问题：当前关节范围与单帧速度限制下，怎样同时满足位置/姿态容差，
而不是用较小总误差掩盖一项越界，也不是让所有已合格配置具有完全相同的零代价。

仓库依据：`dingzhen60027/CG-HIK`，`codex/hierarchical-v5`，
`d345fdbfe24ce2d0dedbf3bfc2c09ee7cb62089b` 的 Task-excess 报告和源码。
未修改远端或原有证据。本包是新数值机制的本地开发，不是独立泛化结果。

## 数学对象

设 e_p、e_R 分别为按原位置/姿态容差归一化的三维残差。

旧 point loss：F=0.5(||e_p||²+||e_R||²)。
上一轮 excess loss：Phi=0.5[||e_p||−1]_+²+0.5[||e_R||−1]_+²。
本轮：M=max(||e_p||²,||e_R||²)。

M<=1 等价于两项位姿条件同时通过；关节范围/速度/有限性继续单独检查。
M在允许域中不恒为零，但在线方法仍可以在找到合格的全步候选后提前返回。
不追加“达标后固定精修N次”，不把公共容差缩小成另一个任务。
这不是闭环稳定性保证。

每次在原固定当前帧区间内解：

    min_d max(f_p(d),f_R(d)) + R(d)
    f_b(d)=||e_b+G_b d||²
    R(d)=lambda/2||d||² + kappa/2||c+W d||²
    lo<=d<=hi

G=J_e S，S_i=qdot_max_i*dt+velocity_tolerance。
c=(q-q_mid)/joint_span，W=diag(S/joint_span)。
κ=0/1均是已存在的设置；居中不是本轮新增机制。

标准凸对偶给出：

    max_{0<=theta<=1} min_{lo<=d<=hi}
        theta f_p(d)+(1-theta)f_R(d)+R(d)

固定theta时仍为一个现有箱约束QP：

    H=2theta G_p^T G_p +2(1-theta)G_R^T G_R+lambda I+kappa W²
    g=2theta G_p^T e_p +2(1-theta)G_R^T e_R+kappa Wc

theta=0.5时，H/g严格对应原GN相同κ下的局部问题（允许浮点舍入差异）。
因此第一步不是额外调用一个原GN求解器，而是同一个对偶问题的对称初值。
它产生的全步命令若通过真实任务验收，可立即返回，标记task_feasible_early，
不能声称已经求到minimax最优。若不通过，继续解同一标量对偶，而不是重启IK。

准确内解下对偶导数为 f_p(d_theta)-f_R(d_theta)。在活动面固定时，
二阶导数为 -z_F^T H_FF^{-1} z_F，z=grad f_p-grad f_R。
用保守括区的Newton更新处理活动面变化。最多16次标量更新、30次外层更新，
这是数值上限而非20ms保证。本原型没有重新发明凸对偶、minimax或活动集。

对非提前返回的子问题，代码保存可行原始上界和带内QP误差修正的对偶下界。
下界修正使用 H>=lambda I 和原箱约束法锥的站立残差；有限精度下属于
数值诊断，不是经过区间算术的形式认证。提前返回时不填造零对偶间隙。

回溯检查真实非线性M下降；局部R含姿态偏好不意味着完整非线性
M+posture具有已证明的全局下降/收敛性质。这里只声称实际检查的M下降。

## 已运行的数值检查

`results/prototype_checks.json`：
- 一维例子 e_p=x, e_R=1.4-0.5x：point optimum为x=.56，不合法；
  minimax平衡点x=14/15，两项残差约.93333。没有新增指定裕度。
- 36个1/6/7维随机凸子问题，与独立冷起点SLSQP epigraph求解对照。
  最大相对目标差约6.43e-8，最大数值原始—对偶间隙约3.92e-7。
  这些检查不代表全部机器人子问题已求到全局精确解。
- 旧Panda trajectory_094/f53的精确输入：新原型找到本地合格配置，
  位置0.963750mm、姿态0.471468度。与上一轮接近1mm/0.5度的解不同。
  该命令仍有一个关节在单帧位移边界附近，不称物理安全裕量。

## 完整本地开发对照（只Panda）

采用之前交付且已由原服务器核对过的同源重建40条轨迹，150帧/条。
本次各方法只运行一遍。方法分别整批运行，未做交错统计，不作速度显著性结论。
全部使用相同本地Numba FK/Jacobian、同一原始box-QP；末次命令由独立Python
齐次变换FK检查。此前原服务器运行方式不同，时间不可与服务器表直接相除。
每帧只读当前目标和实际上一接受配置；失败保持、目标推进；reference_q不进入求解。

| 设置 | 完成/40 | P50/P95/P99 ms | >90%容差的合格命令 | 加速度RMS rad/s² |
|---|---:|---|---:|---:|
| 原point κ=0 |39|.266/.372/.578|.988%|3.0933|
| 原point κ=1 |40|.265/.389/.559|.933%|3.2144|
| 原Phi κ=0 |40|.453/.638/.833|99.267%|3.8049|
| 新均衡κ=0 |39|.338/.443/.641|.988%|3.0933|
| 新均衡κ=1 |40|.314/.430/.635|.933%|3.2144|

以上各自按时完成数与几何完成数相同，只描述本次测量。
新κ=1累计1991.94ms，旧point κ=1累计1713.42ms，Phi累计2811.12ms。
即没有胜过原point的计算成本；相比Phi本次成本较低。不能直接外推服务器收益。
新κ=1与原point κ=1的命令最大差约6.15e-7rad，说明这组完整轨迹主要复用了
原GN本就合格的方向。40/40不是minimax目标的独立完成增量。
新κ=0仍只39/40，不能隐藏这个不利结果。未在本地运行UR5e。

## 开发历史

`development_history/`保留第一份“完整求完对偶再验收、κ=0、0.5倍率目标”
的原型与40条运行：完成39/40、累计约2795ms。它与最终原型同时在停止策略、
损失尺度和κ上不同，不能据此单独归因于某一项改动。
后续选择是复用原GN对应的损失尺度、κ设置，并允许同一个子问题在真实命令
已合法时早停。不存在新增权重网格搜索。所有本地版本都属于开发观察。

## 文件与复现

- `balanced_gn.py`：可移植的单一数值内核，需要注入evaluate/verification。
- `reference/`：之前任务包的Panda模型和原GN/Phi对照，非服务器二进制。
- `data/panda_reconstructed.json`：已观察过的同源重建数据。
- `results/`：每次调用的q、真实previous、接受标志、时间与汇总。
- `check_prototype.py`：数值检查，写new_prototype_checks.json，不覆盖保存结果。
- `run_local_trajectories.py`：本地单遍完整开发对照，写new_local_METHOD.json。

    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python check_prototype.py
    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run_local_trajectories.py balanced

原工程导入时应复用confik.bounded_gn.box_qp，而不是复制一套新后端。
原型的外层deadline不能抢占原生调用；接入需在对偶循环同样检查同一绝对时限，
晚返回完整计入。不要把原型时间当成保证。

## 现阶段判断

支持：可运行的任务均衡数值核心；在选定输入上保留恢复并减少误差贴边；
本地Panda上避免Phi普遍贴边，同时保留原GN相应κ下的任务表现。
未支持：相对原GN的整体完成增量、UR5e收益、泛化、闭环稳定性、全新minimax原理。

下一步目标不是再换任务，而是在原环境验证“少量确有误差冲突的输入能否获益，
普通轨迹是否保留原GN行为”，并检查是否值得对偶运算的额外代价。
