## 1. 唯一方法增量

继续求：
P(d)=max(||e_p+G_p d||²,||e_R+G_R d||²)+R(d)，d在原箱内。

theta=1/2的初始QP与相同kappa的原GN局部方向保持一致。原型只增加一项数值规则：若当前局部上界U、下界L已保证足够比例的模型进展，即

D=P(0)-U>0，U-L <= eta*D，eta固定为0.25，

允许结束局部对偶迭代，转入真实非线性检查，不必每次追求1e-7级局部最优精度。

在实数精确上下界下，D至少达到最优局部模型下降的1/(1+eta)=80%。这不是80%成功率、非线性下降或未来可行性。

下界使用METHOD.md中的箱内强凸下模型，避免把“几乎触界”当精确法锥成员。浮点下界与真实界限分开；U<L超过合理舍入误差时，不得触发保证式停止。

接受当前命令、局部相对进展停止、紧gap收敛、cap/deadline必须分别记录。局部未充分求解和数值失败都不是数学不可行证明。
