## 二、实现唯一新数值模式

复用现有底层运动学、SO(3)残差Jacobian、动态边界、box-QP和最终verifier。
只替换残差空间的梯度/度量与非线性回溯准则。公式和代码见任务包。

Phi=0.5*dist(e, B_p x B_R)^2。
超界块v=(r-radius)u，W=(1-radius/r)I+(radius/r)uu^T；域内为零。
H=G^T W G+lambda I，g=G^T v。
不是用W^T W替代W，也不是仅调整两个标量loss权重。

保持固定于实际previous_q的整个帧动态区间，不能随内部迭代移动并扩大它。
保留lambda起点0.01、最多30外层与原box-QP；首轮固定1e-6归一化内边距。
最终物理合同不变，且仅最终verifier有接受权。
不增加关节居中、预测或平滑惩罚，不为零步再调用另一个IK。

保留原kappa1作为冻结部署对照；新方法不含居中项，所以机制比较以原kappa0
为直接同核对照。不能将去掉居中产生的变化算作新任务度量的收益。

允许修正导数、切换边界、数值舍入和实现错误；不边看轨迹赢家边增加权重。
没有新Git分支、没有TAR/Elastic/Minimal继承或嵌套。

## 三、理论与方法增量

写清楚并实际测试：
1. radius=1时Phi的零集与两个公共位姿条件一致（另需关节、速度、finite检查）。
2. 已达标块不持续要求将其误差压向零；超界块按其法向/切向几何更新。
3. W半正定；lambda>0使局部H正定。
4. 在精确局部QP、0属于边界区间的条件下，
   g^T d <= -d^T H d，可支撑非零方向的局部Phi下降。
   这不是全局可行性、全局收敛或闭环完成保证。
5. 有限精度QP需检查实际方向和实际Phi，不能只信solver success。

这些性质使用现有投影/优化理论，不能称新定理。
对照RangedIK、set-based task-priority IK及generalized/proximal Gauss-Newton，
明确新的候选增量是否是具体任务几何与关节约束的数值结合，而非已知loss换名。
读不到原文的地方明确记录，不按摘要臆测。
