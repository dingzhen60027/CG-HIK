# Figure contract before rendering

These are evidence figures, not submission artwork. No direction of advantage is
assumed before completing the independent comparison.

1. **Question/conclusion to resolve:** does the frozen implementation provide a
   useful task/deadline/cost trade-off, and which controlled differences explain it?
2. **Evidence chain:** task-cost panels show all seven methods on both robots;
   paired-effect panels show GN1 versus each control, using UID-level effects;
   microbenchmark panels show the same QP's full-call time at checked quality.
   Four-family results remain fully inspectable in tables; failure/late frames
   remain in the descriptive latency distributions.
3. **Archetype:** quantitative grids, no decorative diagram or simulated point.
4. **Backend:** existing Python/matplotlib workflow only. Statistics skill fixes
   the unit as a whole trajectory; five micro repetitions and three online repeats
   are nested observations, not additional independent trajectories.
5. **Export:** 183 mm width; readable >=5 pt editable SVG/PDF text, 300 dpi PNG
   previews. Task-cost ranges are the three nested repeat results, paired-effect
   intervals are descriptive unadjusted 95% stratified-bootstrap intervals, and
   QP quantiles are distribution summaries rather than uncertainty intervals.
   Each rendered panel and the exported PDF text size will be inspected.
