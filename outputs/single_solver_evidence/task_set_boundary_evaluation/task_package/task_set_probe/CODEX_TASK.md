## 一、唯一研究问题

在相同位置/姿态容差、关节范围和单帧位移条件下，存在合格命令不意味着
目标中心一定有精确IK解。最小最大任务利用率能否比固定平方和更可靠地
利用这个允许集合，相对进展停止又能否降低为此付出的计算？

现有 point 生成器使用 target=FK(q_ref)，保证精确中心可达。这是有效的
常规对照，不是完整任务集可行域的覆盖。
本轮补的是任务域的边界条件，不把旧点查询/轨迹满分与无增量结论作废。
原轨迹整体不增益的事实保留，不把单帧结果改写成更强闭环能力。

主算法、loss、forcing=.25、kappa=1、迭代预算、后端和verifier均固定。
不再发明第三种目标，不改预测/居中，不加兜底，不搭新框架。

## 三、预先固定几何生成方案

仅 Panda、UR5e。原合同1 mm/0.5°，dt=.02、原速度与物理限位不变。

先随机产生一个合法previous和方向，得到动态边界内的witness。
再作以下目标偏移：

p_d=p(q_w)+alpha*epsilon_p*u_p
R_d=Exp(alpha*epsilon_R*u_R)*R(q_w)

u_p、u_R为独立均匀方向；每个anchor的不同alpha共用方向。
alpha={0,.5,.95}，不能看结果再改阈值。

三个已声明的位移场景：
1. 常规：沿用原local类的位移幅度/方向规则；
2. 高利用：沿用原hard_feasible的幅度/方向规则；
3. 同时接近多关节位移边界：各关节取随机正负号的 .999*v_i*dt，
   再与物理范围相交。明确这是定向压力，不代表部署发生率。

anchor只用几何形成的三类：普通构型、近奇异构型、近物理关节边界构型。
近奇异沿用原几何抽样，不利用任何solver表现挑选。

最终每机器人80个普通+80个近奇异+80个近关节边界anchor；
每个anchor三个位移场景、每场景三个alpha，共2160个query/机器人。
使用全新seed/UID；所有query与witness在方法比较前固定。
不根据失败、成功、cost、对偶theta筛选query、变更类别比例或补样本。

全部q_w必须通过每条自身的原verifier，否则修正生成器本身；
不能通过换到更有利轨迹或放宽verifier来修正。
将“任务集可行”和“精确中心无解”严格区分，后者未经证明一律unknown。

## 四、只用足以分离增量的七个设置

1. 冻结原BoundedGN，kappa=1。
2. 当前CompletedTaskBalanceGN，forcing=.25，kappa=1（唯一主方法）。
3. 同缓存紧精度版，forcing=None，kappa=1。
4. 一个统一固定权重的有界GN：F=theta*||e_p||²+(1-theta)*||e_R||²，
   H/g按一致系数形成，真实回溯使用F，其他动态边界/预算/验收不变。
   theta=.5必须与普通GN一致。
5. 相同minimax局部问题的现有Clarabel epigraph后端，使用相同外层模型、
   动态边界、停止验收和预算，不另行重写一个新预测算法。
6. 正确task-aligned TRAC 5ms。
7. 正确task-aligned TRAC 20ms。

M4检验“一个固定合适权重是否已经足够”，不是故意选弱权重。
只在独立于最终输入的开发部分，以 {0.2,0.35,0.5,0.65,0.8} 选一次。
开发每机器人30个anchor即可，覆盖全部几何/位移/alpha格。
先看两机器人等权verified-success，平局再看平均时间，最后较近.5；
必须固定同一个两机器人通用theta，不为每格和每机器人分别挑选。
这个权重选择只服务于基线，不修改主方法。

M5复用现有EpigraphReference，给与主方法一致的第一theta=.5合法命令
提前退出机会；需要继续时才解同一个锥问题。缓存结构、原生update合理计时。
若复用外层的适配合同不成立，明确报错修正，不悄悄改成不同目标的比较。

不要把TRAC内接Cartesian分量框与公共两个范数球说成完全同一允许集合。
所有返回用同一公共verifier；任务球本身的算法比较主要由M1/M4/M5承担。
不利用之前RangedIK适配失败的数据作优势证据。

## 五、测量与统计

每query每方法三次交错调用；仅当前target、previous_q和dt在线可见。
保存q_w但禁止求解器读取。每query重置状态，不更新成其他query的previous。

主指标：verified-success和20ms内verified-success。
必须按 位移场景×alpha 分表，alpha=0是精确FK对照，不能只展示最困难格。
配对同时给新增成功/损失数、差值、时间比和区间。

同一个anchor衍生的九个query相关，统计时以anchor聚类/按构型类分层；
三个搜索重复是query内重复，不增加样本数。
单遍运行、帧数、重复测量不得当作独立轨迹。
若某格无差异则原样报告，不宣称等效。

辅助：完整P50/P95/P99、平均时间、误差余量、实际求解更新数、
第一theta=.5接受率、继续对偶比例、forcing停止比例。
不把内层80%模型下降说成80%成功保证。

对原GN失败而新方法成功的准确共同输入，附两项误差、固定权重结果、
真实合法命令与数值stationarity诊断；不声称GN局部最优就代表全局无解。
