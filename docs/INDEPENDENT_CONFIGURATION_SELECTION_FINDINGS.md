# 独立状态上的 Panda 冗余构型选择

## 结论：经典指标存在明确反例，但新准则尚未被建立

在本轮全新参考轨迹中，**相同当前输入、实际末端位姿相同的合法构型，确实再次出现不同的后续跟踪结果**。预先固定的近奇异状态 `state_14` 中，三个候选分别完成全部五次 30 帧窗口；最大缩放最小奇异值与最大缩放可操作度却都选中 `candidate_04`，五次均在第 102 帧首次失败。原始 TRAC-IK 候选为 4/5 完成，而不是 0/5。因此这是“经典指标未选中已有的稳定成功候选”的独立反例，不是五条独立轨迹上的恢复。

不过，全样本并没有显示简单构型选择普遍优于保留原解。40 个预定状态中，38 个可用；其中 36 个状态的所有候选均为 5/5 成功，1 个状态结果混合，1 个状态的所有候选均为 0/5。最近解在全部 38 个可用状态都恰好选择原候选；两个经典指标没有恢复任何原候选失败状态，反而把 `state_14` 从 4/5 降至 0/5。候选池的事后最佳结果仅比原解多完成一个搜索重复窗口，不能将其写成已获得广泛收益的新方法。

**最大最小奇异值与最大可操作度不是本批候选的充分续接准则；这也不等于已经证明必须使用新的学习模型。** 它们对当前无方向的 Jacobian 能力给出聚合描述，没有直接编码随后目标方向、关节约束以及固定求解器搜索状态随闭环演化的影响。本轮只确认这种信息缺口对应一个具体反例，没有进一步区分这些可能因素，更没有证明失败构型数学上不可续接。

现有候选生成也不是免费的：中位 **21.48 ms/状态**，加上当前求解和经典指标评分后约 **23 ms**，超过本轮 20 ms 帧周期。评分本身约 1 ms，计算量相对有限；但在没有现成候选池时，当前完整流程还没有显示直接用于 50 Hz 在线选择的成本优势。结论是保留反例和原始证据，停止于机制比较；不新增指标、模型、模式、周期参数或论文修改。

## 1. 全样本与统计口径

独立单位是轨迹/状态，**五次搜索是状态内重复，不是五条独立轨迹**。主要结果保留全部 40 个预定状态：每个可用状态贡献其五次完成比例，未到达状态贡献零“可交付窗口”，然后对 40 个状态平均。未到达的十个计划重复没有实际执行，不能称为十次后续 solver failure。可用 38 状态的条件完成率单独报告。前缀按首次失败前连续成功帧数计算，即使稍后恢复也不重新累计；全样本“交付前缀”对未到达状态记零，条件前缀只使用实际续接窗口。

以下均为固定样本描述，不设总 pass/fail gate，不做显著性检验或总体发生率推断。“稳定”仅指本轮五次结果一致，不是无限次搜索保证。TRAC-IK 搜索不声称固定或配对随机种子；固定的本地 seed 只控制状态及候选/重复的执行顺序。

## 2. 四条规则未带来全样本完成收益

四条规则使用同一个候选池，只读取共同当前输入和候选配置。最近解为到 previous_q 的关节欧氏距离最小；两个经典指标分别最大化同一缩放 Jacobian 的最小奇异值与全部六个奇异值乘积（数值上为 log 和）。精确并列时采用固定候选顺序，不看续接结果。事后最佳仅是完整候选池的诊断上限，不是第五条在线规则。

缩放明确沿用 `A = D⁻¹ J(q) S`：J 是世界坐标系下 6×7 几何 Jacobian；`D = diag(ε_position, ε_position, ε_position, ε_orientation, ε_orientation, ε_orientation)`，使用原公共位姿容差；`S = diag(v_i × 0.02 + ε_velocity)`，使用逐关节允许步长。两个指标都来自这个无量纲 A。未缩放奇异值及 log 可操作度作为辅助字段另存于候选结果，不参与选择，也不与缩放值混用。

候选生成原样复用有限扰动顺序 `(0.25, -0.25, 0.5, -0.5, 0.1, -0.1)`，不扩展范围。以原合法中心实际达到的 FK 位姿为非线性投影目标，固定最大零空间坐标、投影其余六个关节，沿用 200 nfev 的 TRF 预算及原容差设置；只保留通过原 verifier、位姿匹配及去重检查的前五个替代构型。共同 previous_q 的可表示内部边界不变。候选生成和评分函数不接收未来目标或续接结果。

## 3. 一个独立近奇异状态使两个经典指标同时选错

`state_14` 的 seed 为 `970907014`，轨迹 UID 为 `652db5eb389e7355156299a8e5d39fecb8bc55621d923f9a05f415fc9d4a9f4d`。它不是从失败记录中重新定位的状态，而是同样预定的第 74 帧。当前六个候选具有共同 previous_q、共同目标，并匹配原中心实际达到的完整 FK 位姿。

这里指标更大并未对应更好的窗口结果。失败候选 04 的当前关节限位余量还比成功候选 01 更大（约 0.23944 对 0.23514 rad），因此也不能直接解释为“当前离限位更近”。六者当前归一化残差范数均约 0.0014407384；实验匹配的是完整实际位姿，不只是这个范数。

所有 187 个保留替代构型的实际匹配误差，经独立 FK 复核，最大为 **4.55e-16 m / 7.22e-16 rad**，严格低于运行前固定的 1e-8 m/rad。它们全部从共同 previous_q 通过原单帧速度合同，没有跳到当前不可达的 q_ref。

candidate_04 五次均在第 102 帧第一次失败，也就是先连续成功 27 帧；candidate_01/03/05 的五次窗口均真实完成到第 104 帧。以 repeat 0 为例，candidate_04 的第 101 帧位置残差为 8.69 µm、速度利用率约 0.683，当前命令仍合法；第 102 帧原生求解器返回 -3，保留的有限返回状态位置误差为 3.12 mm，未产生可接受命令。candidate_01 在同一目标帧的真实命令位置残差为 2.10 µm、速度利用率约 0.728，并通过 verifier。记录将前者归为 **solver failure**，同时保存其返回状态的 pose rejection；这不是 joint-limit 或 velocity rejection，也不是数学不可行证明。

因此遗漏的信息至少是：**当前局部能力标量没有保持对后续固定目标序列与固定求解过程的正确排序。** 它是否具体来自后续任务方向、约束耦合或求解器搜索域演化，本轮尚未识别，不能把“分支漂移”预设为原因。这里也没有重新计算或优化上一轮的下一目标线性需求，更没有使用未来信息生成候选或选择规则。

在 37 个“池中至少有一个成功重复”的状态中，原解/最近解选中有成功重复的候选为 37/37，两个经典指标为 36/37。在 37 个“池中存在 5/5 候选”的状态中，四条实际规则选中 5/5 候选均为 36/37：原解在 state_14 是 4/5，经典指标是 0/5，不能被同一个 36/37 稳定命中率掩盖。

另一个近奇异状态 `state_18` 的六个候选全部 0/5，全部在第 91 帧首次失败、成功前缀均为 16 帧。这个有限候选池本身没有展示可供规则选择的成功构型，不能归因于选择器选错，也不能证明可续接配置不存在。

## 5. 可复核性与研究边界

运行次序为：固定规则/seed/时间索引 → 生成并封存全部参考身份 → 生成实际历史及候选、保存全部规则选择并封存 → 一次性执行所有唯一候选的五次续接 → 只读汇总与验证。协议、身份与选择分别在 UTC 07:59:14、07:59:29、08:00:13 写入，续接完成时间为 08:03:46；[选择 seal](../outputs/continuation_mechanism_study/independent_configuration_selection/selection_seal.json)绑定候选池和历史原始文件，保存了续接尚未调用的状态。

新参考身份与扫描到的旧身份元数据按 UID、明确记录的 seed 和 query hash 检查，无重叠；扫描文件及覆盖数量写入 [identity_seal.json](../outputs/continuation_mechanism_study/independent_configuration_selection/identity_seal.json)。这是身份元数据检查，不读取旧失败窗口用于本轮筛选，也不将其冒称为覆盖所有未记录身份的全库证明。

独立复核重新检查：

- 6,000 个参考命令及其 query hash；
- 40 段实际历史中的 2,934 个接受命令与真实 previous_q 反馈；
- 全部 225 个当前候选的合法性、187 个替代构型的实际位姿匹配，以及四条规则选择的重算一致性；
- 1,125 个续接窗口、33,300 个接受命令、首次失败和失败后状态保持；
