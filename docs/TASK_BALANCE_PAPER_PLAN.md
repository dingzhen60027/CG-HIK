## 1. 论文身份与主线

建议工作标题：**Task-Balanced Inexact Gauss–Newton for Rate-Constrained Inverse Kinematics**。

一句话：**当位置、姿态分别验收且关节运动受限时，以两块最差容差利用率安排同一个有界GN的局部方向，并用任务验收与已有相对精度原则控制求解工作。**

身份是任务特定的增量数值IK方法；不是新凸优化理论、学习路由、未来可行性预测或实机控制系统。面向工程与机器人期刊组织内容，具体期刊与模板待验收后由用户决定，不在本阶段评价可录用性。

全文因果链固定：

> 分项任务验收与有限关节运动 → 固定误差折中可能得到不合格命令 → 双块任务均衡的有界局部更新 → 更充分的局部求解又可能增加成本 → 任务验收及相对模型进展控制工作 → 受限输入的覆盖—成本证据 → 普通、连续和真实来源负载界定适用范围。

不能改写成“真实任务普遍更快、更鲁棒”。本轮DROID的15/7301额外命令伴随显著成本增加，而且Clarabel/SQP的命令覆盖更高；这些是主结论的一部分，而非附录里消失的例外。

## 3. 三个RQ及现在能够给出的答案

### RQ1：关节运动受限时，任务均衡是否减少固定折中的不合格命令？

- **Opening question**：位置、姿态分别验收时，固定加权误差是否会停在一项精确、另一项越界的折中？
- **必要证据**：准确共同输入的真实命令与两项残差；原GN和预先选定统一固定权重；2160-query全样本与所有九格。不从最有利压力格开始定义总体问题。
- **Closing answer**：受限查询中存在少量可复现的额外合格命令，收益集中于部分任务边界；真实回放也出现15个GN未找到的命令，但普通点已满覆盖。
- **过渡**：更合适的局部任务权衡不是免费的，需要分离覆盖与求解工作。

### RQ2：相对固定工作量、紧解和通用优化，非精确数值组织提供什么覆盖—成本折中？

- **Opening question**：为了找到这些额外命令，必须求多精确、支付多少完整调用成本？
- **必要证据**：同缓存tight、fixed1/fixed2、同minimax外层Clarabel、直接同合同SQP，配合局部QP次数；各表只比较同批资源计时。
- **Closing answer**：受控2160-query负载中，相对停止以较少工作取得紧解/Clarabel/SQP的覆盖，并较fixed2多3/4个命令；这种成本优势没有在DROID外推成立，那里主方法更贵且少于Clarabel一个命令。
- **过渡**：负载改变会改变局部求解的代价，必须检查作用条件而非只报告受控优势。

### RQ3：这种作用在普通、连续、不同合同和真实来源输入中如何变化？

- **Opening question**：任务竞争是否真是这些负载的瓶颈，还是大多数输入用已有首步即可完成？
- **必要证据**：旧独立普通点、完整轨迹、旧合成扫描；新DROID来源核对与等episode配对结果；五固定敏感性。所有来源身份分开，不混为fresh test。
- **Closing answer**：普通点和既有连续轨迹无新增完成；DROID有很小覆盖增量但代价明显，来源witness子集无增量；五个固定开发条件保持覆盖，不证明任意合同或最优forcing。
- **结论衔接**：本方法的价值是特定受限查询上的覆盖—成本选择，不是普遍替换成熟IK或保证连续闭环成功。

### Problem Formulation

输入ξ=(当前请求位姿，实际previous_q，Δt)，两个容差范数、动态箱、数值有限性、独立verifier。区分内部终止、任务接受、20 ms内接受；witness只证明准确输入存在一个合格命令。软件关节合同不相容与一般数值失败分开。

保留一维不合格折中作为解释，并以真实命令补足证据；不把它当完整机器人收敛证明。DROIDΔt=1/15 s与研究计算deadline20 ms显式分开。

### Method

一套符号、一个伪代码：动态箱内局部双块minimax → θ=.5首QP → 当前合格则返回 → 否则同一程序继续并用有效上下界控制局部精度 → 真实FK回溯 → 独立验收。三项数学性质只在假设内陈述。

紧精度版与相对版共用实现；缓存/κ/软截止时间作为实现信息。theta不是路由权重，后续局部步不是fallback链。所有相关数值预算来自冻结代码，不在写作中重新优化。

### Experimental Design

先以三个RQ安排对照，再给数据身份表。说明输入权限、witness不作seed、完整外层计时、硬件线程、预热、重复嵌套、anchor/episode/session聚类和未调整区间。已观察共同输入不改称新独立评估；A source skip和边界不相容输入全部保留。

### Results

按RQ1/RQ2/RQ3组织，不按文件或baseline数量组织。RQ1呈现全样本和所有九格；RQ2以覆盖、时间和工作量三者解释；RQ3拆普通/连续、真实回放、有限敏感性三个段落，不互换任务指标。每节首段提出问题、末段直接回答并衔接，避免机械“answered affirmatively”。

### Discussion、Limitations与Conclusion

讨论何时额外平衡值得付费。明确DROID不能建立总体效率优势，Clarabel可找到主方法漏掉的命令；有限敏感性不是参数最优；原轨迹无新增完成。限制集中说明：精确运动学软件合同、无新硬件/碰撞/动力学验证、软截止、数据选择范围、历史采集配置缺项及闭环外推限制。

结论回到当前命令的覆盖—计算折中。不要再引入未来修正能力、任务规划或“所有IK应采用本法”等超范围结论。
