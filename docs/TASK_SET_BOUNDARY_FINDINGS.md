# Task-set boundary：固定算法的补充适用域验证

基线 `8e4aa63975d465f3de8a1eef2f7773889252c91d`，分支 `codex/hierarchical-v5`。验证前提交（代码、全部新输入、开发结果、固定权重选择）：`00e28a91102e6d71abe03896dbf0d77eb1b0eadc`。

## 三问的答案

1. **受限运动与任务偏移共同出现时，现有 minimax 目标增加了合格命令覆盖。** 在预先固定的 2160 个查询／机器人中，相对进展版、同缓存紧精度版和同外层 Clarabel 均三遍 2160/2160；原 GN 为 Panda 2150/2160、UR5e 2148/2160。相对原 GN 稳定恢复 10/12 个准确共同输入，无损失。收益主要在预定义的多关节位移边界、alpha=.95 格；普通格未显示新增覆盖。
2. **超过本轮合理开发选择的统一固定权重，但没有超过同目标 Clarabel 的合格命令能力。** 独立开发选出的 theta=.35 在新查询上为 2147/2137。它不能替代本轮 minimax 的覆盖；不过所有 minimax 后端都满分，因此不能把任务能力归为标量对偶内核独有，也不意味着不存在其他更合适的固定权重。
3. **相对进展显著减少本次同目标计算工作，同时保留观测覆盖。** 相对同缓存紧精度版，Panda/UR5e 平均时间降低 50.31%/52.85%；相对同外层 Clarabel 降低 17.14%/20.27%。这是这个冻结实现与查询域的外层计时结果，不是同精度裸求解器竞赛或全局理论。

旧精确 FK 点查询 2000/2000、旧独立轨迹相对原 GN 无新增完成的结果仍然有效。本轮仅补充当前查询域，不替代闭环轨迹证据，也不推断现场发生率。

## 2. 固定设计与对照完整性

每台机器人 240 个几何 anchor：普通／近奇异／近物理上限各80；每 anchor 对应3个位移场景×3个偏移，2160查询。独立开发为同构30 anchors／机器人，270查询。**开发与验证的全部输入先于任何新方法比较一起固定**，每个 witness 先通过原 verifier，seed、UID 和 query hash 与旧身份记录、包内探测及另一新 split 隔离。

几何生成不读取求解器表现。alpha=0 时目标是 witness 的精确 FK；alpha=.5/.95 的任务集可行，但精确中心可达性一律 `unknown`。压力位移是 .999×velocity×dt，再作物理裁剪，不能称每关节都使用公共边界的99.9%。在多关节压力格，实际最大公共速度利用率约为 Panda .997090、UR5e .997413；240 anchors 中分别35/23个发生物理裁剪。完整逐关节利用率、方向和裁剪记录保留。

主算法文件、原 GN、动态边界、verifier、NumPy执行路径、forcing=.25、κ1与数值预算均不变。只新增受控对照：固定权重替换原 GN 的 cost/H/g，真实回溯使用同一固定目标，公共停止条件不加权；Clarabel 用实例局部函数绑定替换同一个 completion 外层的方向提供器，保留第一 theta=.5 合法命令直接返回机会。没有全局 monkeypatch、备用IK或未来输入。

五个候选固定权重的两机器人等权开发成功率：.2→97.2222%，.35→99.4444%，.5→99.0741%，.65→97.9630%，.8→95.9259%，所以选 **theta=.35**；没有按验证结果更换。每机器人全部810次开发 theta=.5 与原 GN 的接受结果和 q 完全相同（最大q差0）。22项本轮及已有 completion 回归通过。[完整选择记录](../outputs/single_solver_evidence/task_set_boundary_evaluation/weight_selection.json)、[预先协议](TASK_SET_BOUNDARY_PROTOCOL.md)。

七设置三遍交错调用；单线程数值库、CPU4；记录完整调用外层时间，包含输入处理、求解、全部检查和最终 verifier。初始化与统一预热单列，序列化和离线复验对所有方法同样排除。没有更新环境。统计先在 query 内平均三遍，再按 anchor 聚类、几何类分层配对 bootstrap 4000次；95%区间为描述性未多重校正区间。零差、区间含零和观测满分均不构成等效或普遍保证。

## 5. 真正的恢复命令、误差与数值解释

22个原GN漏解输入均保存全部方法三遍原始输出、独立几何witness和恢复命令。[recovery_commands.json](../outputs/single_solver_evidence/task_set_boundary_evaluation/reports/recovery_commands.json) 按完整UID可定位；所有差异UID及三遍状态在 [gained_lost_uids.csv](../outputs/single_solver_evidence/task_set_boundary_evaluation/reports/gained_lost_uids.csv)。恢复输入是求解前固定集中的结果，不是新生成器的筛选依据。

例如 Panda `116413e5077b1991259016bcb70aed719e9313295c22976aaf3e7971067192d7`，GN归一化位置/姿态为 **.279019/1.094384**，相对进展返回 **.978867mm/.464336°**，固定权重仍失败。UR5e `d0dce9ba3a0457e8a0eff3d503d9012e6fe49e92fdffa612be99cf47bc7cc131`，GN为 **1.092701/.555249**，相对进展为 **.911827mm/.467064°**。因此失配不只是一种固定“姿态比位置重要”的方向，两个任务块都可能是越界项。

Panda 10个失败是位置达标而姿态越界；UR5e有4个位置越界、8个姿态越界。原GN停止状态为 `stationary` 或 `no_descent`，离线在准确保存的终点复算归一化梯度投影：Panda最大约6.53e−4、UR5e最大约3.12e−5。诊断包括原κ1居中项、实际动态箱和完整残差向量；**没有另外运行优化器来“改善”原输出**，也不把这些数值当精确KKT、全局最优或中心不可行证明。

全部合格命令的>90%容差利用率：相对进展 Panda **6.667%**、UR5e **6.574%**；原GN **6.279%/6.052%**，紧精度 **7.546%/7.685%**，Clarabel **7.361%/7.130%**。新覆盖伴随少量更多边界附近合法命令，不能据此推断后续跟踪更好。实际误差分布和最大值都保存，未隐藏或收紧公共验收。

第一theta=.5 QP直接合格的调用占 **57.407%/47.222%**；需要进入后续局部逻辑占 **42.500%/52.685%**。相对进展在这些调用中至少一次达到forcing条件，而只有 **0.463%/0.556%** 的全部调用需要同一局部问题多于一个QP。平均局部QP数为 **1.457/1.562**，同缓存紧精度为 **3.921/4.699**。这些是明确分母的工作量统计，不把模型下降比例写成80%成功保证。

## 6. Problem–Method–Evidence 与已有工作的边界

| 项目 | 本轮可支持的具体内容 | 尚不能据此主张 |
|---|---|---|
| Problem | 有界运动下，已知存在任务合格命令，平方和GN仍可能停在一个块越界的配置；两个越界方向都有实际输入。 | 所有非零偏移的目标中心均无精确解；部署中此类输入的发生率。 |
| Method | 冻结双块minimax及相对进展；一个局部对偶，动态箱与原verifier。没有新增算法。 | 首次容差IK、首次集合任务、首次对偶、全局非线性收敛。 |
| Evidence: coverage | 新、先固定的两机器人查询上稳定新增10/12个原GN合格命令，超过开发选择的固定权重，未损失普通格。 | 相对所有固定权重或所有成熟优化器的能力优势；Clarabel本轮同样全部成功。 |
| Evidence: cost | 同缓存紧精度约50%/53%降耗；同外层Clarabel约17%/20%降耗，保留观测覆盖。 | 同精度裸内核全面优越，或每类/每个分位数均加速。 |
| Closed-loop boundary | 旧独立轨迹Panda78/80、UR5e80/80，与同κ原GN完成集合相同的事实保持。 | 新增完整连续跟踪能力；用本轮单帧恢复替代TSR/DTSR证据。 |

RangedIK 已在统一优化中处理固定、范围和偏好任务，使用加权多目标与范围损失；本轮不是首次利用允许误差，也没有完成对RangedIK的性能对照。[Wang et al., ICRA2023](https://graphics.cs.wisc.edu/Papers/2023/WPRG23/)。

Set-based task-priority IK 已将允许集合直接纳入分层控制，给出特定假设下的稳定性与实验；本轮是位置/姿态两个范数球的同优先级minimax数值求解，不继承其分层连续系统保证。[Moe et al., 2016](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2016.00016/full)。

非精确GN已有按子问题精度控制工作的理论。本轮只应用局部模型上下界终止，不把相应信赖域收敛结论移植到有限预算、任务提前接受的IK循环。[Porcelli, Optimization Letters7:447–465, 2013（online2011）](https://flore.unifi.it/handle/2158/1351282)。三项引用经Crossref及出版方/作者来源核对，记录在 `literature/verification.json`。

有限数学性质：在有限、关节/速度合法条件下，M=max(||ep||²,||eR||²)≤1对应两项位姿验收；局部epigraph两个乘子的和为1，形成theta与1−theta。有效L≤P*≤U、P0>U且U−L≤.25(P0−U)，推出取得至少80%的最优正则局部模型下降。浮点异常不得宣称成立；本轮复验了7005个保存的forcing界记录。它不是非线性成功或轨迹保证。
