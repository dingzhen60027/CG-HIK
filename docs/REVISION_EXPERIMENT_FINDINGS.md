# 补充实验：计算分配的五个问题

本报告先于本轮论文修改完成。CG-HIK 主方法直接加载冻结 release；没有重新训练、调阈值或改变 solver/verifier。新增数据为 supplementary evaluation，旧轨迹重新分组为 post-hoc descriptive analysis。两台机器人各 3,000 个点查询（三次交错调用）、500 个入口诊断查询（每入口十次）、40 条 × 150 帧参考可行轨迹均已完整测量。区间为 4,000 次按类别分层的配对 percentile bootstrap 95% 区间；独立单位是查询或完整轨迹，不是重复调用或帧。不设总 gate。

## 1. 学习入口选择本身是否优于固定 hard 和简单规则？

在新增的 witness-feasible 点查询上，没有观察到这种优势。六个内部策略的 verified success 完全相同：Panda 94.92%，UR5e 100%；所有有 witness 的查询均无 learned false reject。去掉早拒绝的 routing-only 仍比不支付无用预测开销的 always-hard 更慢，FEV 未降低。

| 可行点查询比较 | Panda 时间比 [95% CI] | UR5e 时间比 [95% CI] |
| --- | --- | --- |
| Routing-only / hard | 1.0334 [1.0296, 1.0382] | 1.2935 [1.2864, 1.3003] |
| Full / hard | 1.0333 [1.0293, 1.0382] | 1.2932 [1.2861, 1.3000] |
| Full / geometry rule | 1.0009 [0.9997, 1.0022] | 1.0017 [0.9978, 1.0055] |
| Full / reject-only + hard | 0.9998 [0.9983, 1.0013] | 1.0016 [0.9979, 1.0053] |

Full 相对 hard 的配对平均开销为 Panda 0.503 ms [0.486, 0.525]、UR5e 0.448 ms [0.440, 0.455]。对应 FEV 比为 1.0012 / 1.0005。Geometry rule 仍复用相同预测器做 reject/defer，因此这里检验的是“入口排序是否需要学习条件代价”，不是完全无模型系统。

同一 policy-validation 子集的五路比较已保存于 [same_population_routing_comparison.csv](/home/eric/wjg/btry/outputs/revision_compute_allocation/01_existing_result_decomposition/same_population_routing_comparison.csv)：Panda 2,031、UR5e 2,049 个成功且未 abstain 的查询。路径数值求解与 verifier 的平均时间单独列出；旧标签流水线时间单独列出；未实测的部署端到端开销留空。未把不同总体的 best-fixed gap 与 routing regret 直接比较。

独立十次入口诊断进一步显示：两折入口偏好一致率仅 41.61%（Panda，471 个两折都有成功入口的查询）和 43.80%（UR5e，500 个）。Panda 另有 29 个查询两折都没有成功入口，不能算稳定的成功入口偏好。用一折选择、另一折评价的平均时间比（相对 hard）为 0.9978 [0.9949, 1.0002] / 1.0015 [0.9988, 1.0042]；57.6% / 78.0% 的查询三个入口的十次平均时间极差不超过 0.15 ms。低 regret 很大程度上与入口成本接近、经验赢家不稳定相容，而非已经证明了强可利用排序信号。

## 2. P95 选择相比 P50 选择是否有直接收益？

有小幅数值工作收益，但没有明确的尾时延独有优势。该比较只改变 eligible entries 内的排序目标，保留原成功阈值、P95 eligibility、reject/defer 和 tie-rule；P50 是中位数，不是 mean。

| Full P95 / P50-selection，可行查询 | Panda | UR5e |
| --- | --- | --- |
| FEV 比 [95% CI] | 0.9942 [0.9925, 0.9958] | 0.9814 [0.9737, 0.9890] |
| 平均时间比 [95% CI] | 0.9985 [0.9970, 0.9999] | 0.9983 [0.9942, 1.0022] |
| 实测 P95 比 [95% CI] | 0.9969 [0.9758, 1.0101] | 0.9885 [0.9615, 1.0099] |
| 实测 P99 比 [95% CI] | 1.0002 [0.9984, 1.0020] | 0.9365 [0.8644, 1.0527] |

P95 决策降低 FEV 约 0.58% / 1.86%，Panda 平均时间约减少 0.024 ms；两台机器人成功率均不变。但 P95、P99 的配对区间均跨 1，不能据此把 P95 目标写成已经实证必要的尾时延机制。以上为描述性区间，未做多重比较显著性宣称。

## 3. 成功求解与失败处理分别贡献了多少节省？

旧 transition-rich 正式结果的全样本节省主要位于共同失败组，而不是共同完成组。

| 旧轨迹分组 | Panda 条数 | Hard / CG-HIK 累计秒 | UR5e 条数 | Hard / CG-HIK 累计秒 |
| --- | --- | --- | --- | --- |
| 两者完成 | 40 | 10.142 / 11.347 | 34 | 7.991 / 8.986 |
| 仅 CG-HIK 完成 | 1 | 3.404 / 0.290 | 0 | 0 / 0 |
| 仅 hard 完成 | 0 | 0 / 0 | 0 | 0 / 0 |
| 两者未完成 | 39 | 458.498 / 255.676 | 46 | 130.237 / 53.280 |

共同完成组分别慢 11.88% / 12.45%，对净节省的贡献为 −0.59% / −1.31%；共同失败组贡献 99.07% / 101.31%，Panda 仅 CG-HIK 完成的一条贡献 1.52%。大于 100% 表示该组节省抵消了其他组的额外成本。四组累计时间和 FEV 严格加总回原始全样本；各组的 FEV、轨迹中位时间、reject/defer/fallback、首次失败及原因都在 [分解表](/home/eric/wjg/btry/outputs/revision_compute_allocation/01_existing_result_decomposition/trajectory_savings_decomposition.csv)及同目录逐轨迹明细中。分组依赖观测结果，只作描述性成本归属，不作因果证明。

新参考可行轨迹中，Full 相对 routing-only 节省 45.90%（Panda）和 8.83%（UR5e）累计时间，完成集合不变。133 / 68 个 Full reject 事件的 no-reject 对照均接收了完全相同的查询，却没有返回一个 verified command。这直接显示了这批观测中拒绝所避免的无效 hard 调用，但不是不可行性的数学证明。

新增共同完成组的累计时间仍分别增加 18.23%（34 条，时间比区间 [0.9736, 1.3278]）和 32.12%（36 条，[1.3166, 1.3257]）。Panda 该组 FEV 为 16,607 → 15,108，说明确有部分有效求解数值工作减少，但被固定部署开销抵消；UR5e 为 16,042 → 16,052。Panda 新全样本的净节省全部由共同失败组的大幅节省提供，同时抵消共同成功和丢失成功轨迹的额外成本。UR5e 共同失败组省 1.303 s，但共同成功组多花 2.374 s，合计反而慢 1.071 s。

## 4. 连续可行轨迹上是否仍能保持完成并降低计算？

不能作跨机器人一致的肯定回答。所有参考路径都经过原 verifier 离线检查，但在线方法只能使用自己的上一接受状态；参考路径可行不保证偏离后仍可恢复。

## 5. 相比 TRAC-IK，当前方法的实际价值在哪里？

在本次精确运动学、单步限位约束的可行负载上，TRAC-IK 给出明显更好的耗时位置。Panda 可行点 verified success 为约 97.83–97.93%，高于 CG-HIK 的 94.92%；UR5e 为 99.947–99.960%，CG-HIK 为 100%。不把这一小幅 UR5e 点成功率优势写成总体优越性。

| 可行点 / 方法 | Panda 成功 %；P50 / P95 / P99 ms | UR5e 成功 %；P50 / P95 / P99 ms |
| --- | --- | --- |
| TRAC-IK 5 ms | 97.907；0.230 / 0.475 / 0.646 | 99.947；0.214 / 0.347 / 0.431 |
| TRAC-IK 20 ms | 97.827；0.230 / 0.472 / 0.645 | 99.947；0.214 / 0.347 / 0.425 |
| TRAC-IK 100 ms | 97.880；0.229 / 0.471 / 0.656 | 99.960；0.214 / 0.348 / 0.423 |
| TRAC-IK 400 ms | 97.933；0.230 / 0.472 / 0.646 | 99.960；0.214 / 0.352 / 0.433 |
| CG-HIK | 94.920；1.984 / 90.488 / 348.073 | 100.000；1.793 / 2.479 / 4.020 |

相对 5 ms TRAC-IK，CG-HIK 可行点平均时间比为 Panda 59.31 [52.20, 66.38]、UR5e 8.50 [8.37, 8.63]；成功率差 −2.987 pp [−3.747, −2.253] / +0.053 pp [0.000, 0.160]。四预算按实测返回时间绘图，没有把超时成功算成按时成功。5 ms 外部可行点失败包括 Panda 157 次公共 velocity verifier 拒绝；UR5e 三次该类拒绝与一次 solver failure。这些均保留为失败，未按 solver 返回码改算成功。

轨迹预算在旧 calibration 上独立选为 5 ms。TRAC-IK 完成 Panda 36/40、UR5e 39/40，累计时间 3.040 / 1.699 s，且这些完成轨迹也全部逐帧在 20 ms 内返回。CG-HIK 为 34/40、36/40，时间比分别为 12.83 [6.44, 21.91] / 10.02 [7.08, 14.87]。Panda 完成集合不互相包含：CG-HIK 相对 TRAC-IK 丢失四条、额外完成两条；UR5e 丢失三条、无额外完成。外部 FEV 不可比，未强行报告。

因此，当前证据的实际价值是对同一学习—数值求解组合进行可解释的计算分配与失败处理分析，以及展示确定性接受边界如何约束所有策略；它没有建立比成熟 TRAC-IK 更高效的通用在线 IK 方法。论文应保留原固定 easy 级联上的正式收益，清楚呈现补充实验识别的机制和正面局部例外，同时把“入口选择必要性”“P95 独有优势”“成功轨迹总体加速”写成已检验但未获普遍支持的假设。后续仅整理冻结方法的论文，不开发新的时序版本。
