# Final claim–experiment map

Updated: 2026-09-04

This map separates development evidence, frozen fresh point evidence, and the final
fresh transition-rich trajectory evaluation. Numerical values used in the manuscript
are generated by paper/scripts/build_evidence.py; this document explains what each
source can support.

## RQ1 — Computation heterogeneity and predictability

**Claim.** Queries differ in which shared cascade entry minimizes observed tail cost,
and the frozen router captures enough of this ordering to achieve low regret.

**Source.** outputs/counterfactual_v4_bulk/ and the frozen policy artifacts in
outputs/release_v4_locked/.

**Evidence.**

| Development metric | Panda | UR5e |
|---|---:|---:|
| Oracle easy / medium / hard | 26.69 / 27.77 / 45.54% | 23.41 / 25.36 / 51.22% |
| Hard minus oracle, mean empirical-P95 gap | 0.137 ms | 0.154 ms |
| Exact oracle agreement | 47.42% | 53.88% |
| Routing regret, mean / median / P95 | 0.135 / 0.016 / 0.467 ms | 0.133 / 0.000 / 0.605 ms |

**Boundary.** The policy-selection split is disjoint from fitting and calibration but
is development data. Five timing repeats make the empirical oracle a noisy diagnostic,
not a confirmatory performance result.

## RQ2 — Fresh point-query system performance

**Claim.** Relative to the Fixed robust cascade, CG-HIK preserves feasible verified
success while reducing mean FEV and P95, and it avoids most numerical work on the
constructed known-infeasible subset.

**Source.** outputs/test_v4_aggregate_repair_v1/.

**Primary seed-17 evidence.**

| Metric, CG-HIK vs fixed | Panda | UR5e |
|---|---:|---:|
| Feasible success gap | 0 | 0 |
| Mean FEV reduction | 16.14% | 36.27% |
| P95 ratio | 0.7538 | 0.7427 |
| P99 ratio | 0.9931 | 0.8808 |
| P50 change | +16.47% | +16.45% |
| Known-infeasible reject recall | 95.65% | 93.95% |
| Known-infeasible FEV avoided | 95.69% | 93.92% |
| Point OOD AUROC / AUPRC | 0.430 / 0.210 | 0.504 / 0.230 |
| Defer semantic match / recovery | 100% / 0% | 100% / 0% |

**Boundary.** The legacy frozen suite's eight hypotheses---six point margins and two
trajectory-completion margins---passed joint Holm correction. The legacy trajectory
arm is distinct from the final transition-rich evaluation below.
The separate Panda operational gate failed because a strictly positive OOD-feasible
false-reject improvement was required while both methods had zero false rejects.
Therefore the point-study paper gate is false. Seeds 29 and 43 reuse the same test
queries and are sensitivity runs, not independent samples.

## RQ3 — Fresh transition-rich trajectory performance

**Claim.** Relative to the Fixed hard-entry cascade, frozen CG-HIK preserves or
improves whole-trajectory completion while reducing aggregate cumulative latency,
mean FEV, and P95 on both robots.

**Source.**

- outputs/fresh_transition_v4_test/family_table.json
- outputs/fresh_transition_v4_test/completion_uids.json
- outputs/fresh_transition_v4_test/final_gate.json

**One-shot evidence.**

|---|---:|---:|---:|---:|---:|---:|---:|

| UR5e | 34/80 vs 34/80 | −54.95% | −65.12% | +11.09% | −21.94% | −23.09% | 0 |

The final gate passed for both robots. P50 was preregistered as report-only.

**Family interpretation.**

| Family | Panda cumulative change | UR5e cumulative change | Supported reading |
|---|---:|---:|---|
| Smooth–fast orientation–smooth | −29.62% | −9.44% | Moderate savings |
| Regular–near singular–regular | −59.26% | −59.60% | Strongest, repeatable savings |

**Boundary.** Each method evolves a method-specific closed-loop joint state. Paired
frames share trajectory UID, time index, and exogenous target, but not necessarily the
same previous configuration after branch divergence. The independent descriptive unit
for completion is the whole trajectory.

## Claim discipline

| Supported | Not supported |
|---|---|
| Query-specific tail-latency routing over one shared solver portfolio | A new numerical IK solver |
| Learning allocates computation; numerical geometry generates commands | A neural network directly authorizes commands |
| Lower aggregate latency, FEV, and P95 in the final two-robot trajectory test | Every query, quantile, robot family, or platform is faster |
| Zero violations of the implemented kinematic contract | Collision safety, physical safety, or certified real-time control |
| Conservative OOD defer semantics | Strong OOD discrimination or observed defer recovery |
| Exact URDF/Pinocchio closed-loop kinematics | Isaac Lab physics, dynamics, contact, torque, controller tracking, or real robot |

## Historical development analyses

V5–V7 investigated per-frame gates and temporal local shortcuts. They remain
development-only mechanism evidence: local-success runs can be long, but persistent
local branches can change future recoverability near singular and transition-rich
segments. They are not comparators in the final trajectory test and must not be
presented as versions of the final method.
