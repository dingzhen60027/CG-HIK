# Phase 2：全局端点图与局部换行时间优化

本轮只使用已观察的24开发场景。旧Phase1.5、旧IK数学内核、verifier和论文不改。
起始基线为74d127c712d771b6ba03ab22432ff3ad2f3ac21b。无正式96场景入口。

## 固定输入与候选

沿用Phase1.5的全部场景UID、共同关节首末态、10/14条扫描线、3mm端点延伸、
1mm重叠余量及共同物理设置。候选只读取独立参考构造的多启动IK层，逐一用当前
FK、URDF范围、完整工艺域和5mm碰撞间隙复核；不读取B0/B1/B2最终路径。
每个扫描线端点一层，保留参考成员，再按URDF跨度归一化关节距离最远点取样，
欧氏1mrad去重、字典序打破并列、最多12个。首末层只保留冻结共同状态。
原多启动种子2026091701保留；本轮不根据方法结果补候选。

中间参考IK层提供相邻端点的离线连续性见证。细边最大单关节差0.35rad，
在三个内部等分点检查完整工艺域与碰撞；每个端点对使用这些细边上的固定
最小归一化平方步长路径。它只是有限离散检查，最终仍必须通过3201点整样条
几何检查、TOPPRA及6401点运动检查。两种端点图共用全部候选、细边、剪枝及
中间见证；禁止为时间图另选更宽松可行性判据。

## 两个边代价

A1：`sum_i ((q1_i-q0_i)/(qmax_i-qmin_i))²`。

A2/Proposed：每关节公共速度上限`v_i=0.5*URDF_velocity_i`、加速度`a_i=2`。
在节点q处，任何全局起止静止、始终满足关节范围和加速度的运动必须满足
`|qdot_i| <= c_i(q)=min(v_i,sqrt(2*a_i*(q_i-qmin_i)),sqrt(2*a_i*(qmax_i-q_i)))`。
这是从获得速度与未来制动所需的最小距离得到的必要条件。共同起点/终点速度
上界设为0，内部端点**不强制停住**。

对一条边，以两端c值作边界速度的松弛上界，记
`C_i(T)=integral_0^T min(v_i,c0_i+a_i*t,c1_i+a_i*(T-t)) dt`。
必要条件为`abs(q1_i-q0_i)<=C_i(T)`。逐关节解析分段积分与固定48次二分取
满足条件时间的下侧端点，再取所有关节最大值。它忽略任务、碰撞和联合关节
耦合，因此是运动学松弛下界，不是预测的真实换行时间，不是全局最优时间。
每条边保存q、物理范围、速度/加速度、边界包络、各关节下界及公式。
分层最短路的首尾是硬约束，不能事后替换末态造成跳变。

## 共同路径与局部优化

图路径使用原96控制点C²三次样条拟合。拟合不合法时，只用已有完整工艺域
约束平滑器进行30s共同几何拟合；仍失败则保留失败，不更换节点/边代价。
拟合可以偏离内部选中端点配置，但必须仍满足工艺域；偏离量单独记录。
共同首末关节状态始终固定。图连通、样条合法和物理质量合格分别记录。

A2止于该路径与TOPPRA。A1与Proposed分别从距离/时间图路径出发，使用完全
相同局部精修。开放范围为每个换行段及两侧各20mm路径参数长度的边界层。
只开放支撑完全位于该范围的样条控制点，故扫描直线内部的关节路径严格不变。
工具位姿通过FK在原允许域内联合变化；不另添姿态损失或预测器。

局部优化直接复用经验证B2的构型—时间NLP：相同目标、尺度、梯度、Hessian、
节点、速度/加速度/采样约束、IPOPT设置与密集验收。区别仅为把非局部系数和
局部区域外时间变量固定到初值。每个合格更新后整路径重新TOPPRA，只有真实
重定时时间降低且验收完成未超过30s才进入incumbent。B2-common由同一实现
开放全部变量，和Proposed/A2逐字节共享每遍的图初值。旧B2代码保留不改。

未扫描换行仍使用Phase1.5代码中的完整工艺域与碰撞要求；不因无采样而放宽。
共同速度余量0.90、控制器400/40、1ms物理步长、2ms控制周期和200Hz射线不变。

## 运行与计时

B0/B1直接调用原Phase1.5实现，仅重定向输出；保留其10s主检查点定义。
A1/A2/Proposed/B2-common在同一批资源运行。新精修设置取30s内最好已验收路径，
同时保存1/5/10/30s记录；因此不把B0/B1与新设置误称相同优化目标/预算。
每场景三次规划、仅预指定repeat0力矩执行一次，共432条件、最多144次执行。
所有三遍先在场景内平均；机器人分开，CAD×放置6簇、方向嵌套，4000次配对
聚类bootstrap、种子2026091607。失败时间null，全样本质量率并列共同成功成本。

候选复核、图构建、拟合、优化、密集检查和重定时均计入方法成本。冻结多启动
参考库的历史采集为共同输入准备，单独披露，不把缓存重用称从零IK生成速度。
每遍图公共构建只实际做一次，其实测费用完整计入四个消费方法；共享初值不
重复运行以制造不同起点。单独报告图费用与优化增量费用。

“达到B2-30s时间105%”同时列计划代理和实际已执行路径。未执行的检查点仅是
几何/定时合格，不能声称物理质量已验证。物理认证的首次可用时间仅追溯到最终
实际执行的同一系数路径首次验收时刻，不能据未执行路径推断更早物理通过。

开发Gate完全按用户六项要求，不能通过换场景、改阈值或增加第三边代价追求通过。
全局图、冗余/容差覆盖规划与路径—时间优化均有成熟基础；本轮只检验这些具体
组合及局部范围是否改善冻结任务，不预写算法有效性结论。
