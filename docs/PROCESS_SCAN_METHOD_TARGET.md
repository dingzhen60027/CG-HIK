# 后续方法的固定研究对象（本轮不实现）

研究对象是完整质量合格扫描的实际cycle time，不是单点IK残差，也不是让旧TB
对偶在当前数据上人为激活。扫描直线段保持固定，允许变化的部分仅为换行过渡
和两侧邻近边界层。变量是工艺允许域内的工具姿态、关节构型与时间分配；扫描
ROI、工件放置、扫描顺序、碰撞要求、采样和物理质量阈值不变。

共同初值与参数化来自冻结的B1可行路径。未来主方法按时间敏感性选择需要更新
的块；同核消融为均匀选块和几何曲率选块；B2是所有构型—时间变量同时可变的
参照。不得给候选方法更好的初值而不给B2。没有本轮代码实现这些选块规则。

目标评价按“完整质量合格率、共同合格场景的真实cycle time、规划成本”并列，
不把未完成扫描的短停止时间当收益。位姿、碰撞和插值的几何检查、定时速度/
加速度检查、实际力矩控制、真实回波覆盖是不同验收层。时间敏感性不能由一个
速度约束的活动比例直接冒充；预先的扫描/换行分段和物理记录用于识别问题，
不构成已经有效的新梯度或选块算法。

|Jonathan Fried、Santiago Paternain，*A Bi-Level Optimization Approach to Joint Trajectory Optimization for Redundant Manipulators*，2024预印本，[原文](https://arxiv.org/html/2412.07859v1)|固定路径的时间子问题与上层关节路径更新；利用值函数方向信息联合考虑关节位置、速度和加速度|有限规划预算下的局部时间敏感性选块是否优于均匀/曲率选块及可信全变量参照|
