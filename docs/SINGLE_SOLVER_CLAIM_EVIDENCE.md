# 方法差异与 claim–evidence（两页以内）

更新：本次真实受限 QP / 官方 qpOASES 跟进以 `be75d28` 为基线；旧独立轨迹数字不变。[新证据](SINGLE_SOLVER_CONSTRAINED_QP_FINDINGS.md) 限定了原先“专用内核效率”的适用范围。

## 1. 方法差异：成熟成分与具体实现

本轮没有发明 Gauss–Newton、关节居中、活动集或约束 QP。冻结实现以原任务容差归一化残差，以 S=diag(velocity·dt+εv) 归一化步长；在围绕**实际上一接受状态**固定的动态区间内，迭代求局部箱约束 QP。局部模型含 λI 阻尼和 κ 居中项，非线性回溯却仅要求任务残差下降。进入原任务容差后停止，公共 verifier 独占接受权。没有新收敛定理或全局可行性证明。

| 已有工作 | 已具备的能力 | 本轮可说与不可说 |
|---|---|---|
| 约束 GN/SQP；TRAC-IK | 数值精修、边界约束、局部优化；TRAC 的 Newton/SQP 并行求解与原生容差 | 当前是固定帧区间、尺度和停止条件的具体组合。TRAC 不是“只会裁剪”的对照；主方法不保证全局最优，也不是新 SQP。 |
| SNS（Flacco 等，2015） | 受限关节饱和、其余关节重分配、任务缩放、QP 最优性分析 | “边界内重分配”已存在。我们测得当前 GN 内联合求步相对**同核后裁剪**的差别，不推出胜过 SNS；不运行任务缩放或重定时。 |
| Pink 微分 QP | 加权任务、关节范围及速度约束 | 比较的是冻结 pin-pink 3.3.0 单步适配器，不是全部 Pink 控制器。不能称首次将限位放入 IK。 |
| LoIK（Wingo 等，RSS 2024） | 利用运动学树结构的增广拉格朗日/ADMM 与线性复杂度子问题 | 本轮只测 6/7 维密集 QP，没有相同复杂度结果，也没有 LoIK 性能对比。 |
| OSQP | 缓存矩阵数值更新、原生 warm-start、polishing | M4求相同QP；原自然库双方均合格。新增受限库原上限出现失败，离线提高上限后仍有3个Panda输入不合格，保留且不算速度胜出。 |
| 官方 qpOASES 3.2.1 | 变 Hessian 的 SQProblem 热启动、成熟在线活动集策略 | 相同原/定向矩阵均合格且比当前 NumPy 活动集更快；不支持专用内核相对同类成熟实现的效率优势。 |

来源与核查链接集中在 [原论文/官方实现清单](../outputs/single_solver_evidence/protocol/literature_scope.md)。现代约束 IK 的能力不以裁剪消融为代表。

## 2. Claim–evidence 与停止判断

| 主张 | 当前证据 | 判断 |
|---|---|---|
| 固定单求解器仍有实际价值 | 新 160 UID/机器人，三遍 GN1 均完成 Panda 154、UR5e 158；接受命令零违约 | 支持当前软件、资源和负载内的工程有效性，不支持普遍满分/硬实时。 |
| 有界协同求步改善续接 | 旧轨迹 Panda 多4条、UR5e一得一失；六处最早显著方向差异的 previous_q 精确相同，有界方向重分配其他关节并降低真实残差 | 局部数值机制有直接证据；UR5e失利例也有更好局部下降，故不能将其当成充分续接保证。 |
| 居中项是独立贡献 | Panda 三得三失；UR5e 只丢失 1 条；κ=1 加速度 RMS 更高 | **不支持。** 不事后换主方法，不包装正面作用。 |
| 专用内核领先成熟同类 | 对官方qpOASES，定向库UID等权完整调用反而慢36.2%/33.6%；双方所有输入质量合格 | **不支持。** 旧相对OSQP降幅只是后端/接口相关；常规组OSQP原生solve也更快，NumPy主要省接口开销。 |
| 整轨迹效率体现上述差别 | 相对同核 OSQP，累计时间少 31.6%/18.2%；共同成功UID仅少约 8% | 支持实测效率，须同时披露失败尾部对总量的贡献。 |
| 全面超过 TRAC/Pink | 对 TRAC5，TSR点估计较高但总成本 +1.1%/+18.9%；共同成功UID慢约48%/52%。对当前 Pink，总成本少66%/58%，UR5e TSR +10 pp | 支持部分完成—成本折中，不支持“普遍加速成功求解”。Panda 多个完成差区间跨零。 |

证据入口：[完整报告](SINGLE_SOLVER_NECESSARY_EXPERIMENTS.md)、[主表](../outputs/single_solver_evidence/reports/main_table.csv)、[配对区间](../outputs/single_solver_evidence/reports/paired_comparisons.csv)、[QP质量—时间](../outputs/single_solver_evidence/reports/qp_quality_time.csv)。统计单位是轨迹 UID，不是重复调用；区间未经多重校正。相同观测向量或区间跨零均不构成普遍等效证明。

**贡献判断：** 有效、可复用的工程实现，加上受控边界机制和小规模内核效率证据；不足以宣称新的约束 IK 原理。居中创新主张应舍弃。无需为本轮结果新增网络、目标或模块；本轮停止实验开发，不修改论文。
