# Task Balance GN：最终方法归属与主张范围

## 问题与一个完整方法

**位置与姿态分别验收，而固定误差折中允许一项精度补偿另一项超差；在关节运动受限时，两者的区别会影响是否有命令可交付。** 当前研究对象是这一具体接口中的数值命令生成，不是学习路由、未来可行性预测或新的通用优化理论。

输入为当前请求位姿、实际上一状态和运动周期。位置1 mm、姿态0.5°是名义软件合同；关节范围、速度及数值容差沿用项目定义。运动周期决定可达关节箱，20 ms计算评价期限是另一量。DROID回放的输入周期为配置重建的1/15 s，不能套用开发输入的20 ms。

Task Balance GN是一套任务特定的数值组织：在固定于输入上一状态的动态箱内，以两个归一化位姿块的最差平方利用率形成局部模型；先求θ=.5的有界QP，已有任务合格命令立即交原verifier，否则继续同一个局部双块问题，以任务验收或已有相对精度原则控制局部工作。真实FK回溯和最终命令验收独立保留。θ是局部对偶变量，不是按机器人调节的策略权重；继续局部求步也不是原GN失败后调用另一IK。

本轮没有修改主实现。κ=1、forcing=.25、原阻尼、30次外层检查／16次局部更新／8次回溯及20 ms软期限全部冻结。敏感性实例没有替换它。源码与verifier前后hash及记录入口见[最终证据](TASK_BALANCE_FINAL_EVIDENCE.md)。

## 数学依据：性质、假设和归属同时给出

设世界坐标归一化残差为

\[
e_p=(p^d-p(q))/\epsilon_p,\qquad
e_R=\operatorname{Log}(R^dR(q)^T)/\epsilon_R,\quad
M(q)=\max(\|e_p\|^2,\|e_R\|^2).
\]

1. **验收对应。** 对有限、已经通过原关节范围和单帧速度检查的配置，且FK、旋转距离和容差与verifier一致，M≤1恰对应两个位姿条件同时通过。时间不在此等价式内，含正则项的局部目标也不是最终验收量。这是集合定义与最大值的直接性质。

2. **局部强凸性与标量对偶。** 令S为原单帧关节尺度，G=JₑS，局部非空箱为B，

   \[
   P(d)=\max(f_p(d),f_R(d))+\mathcal R(d),\quad
   f_b=\|e_b+G_bd\|^2,\quad
   \mathcal R=\lambda\|d\|^2/2+\kappa\|c+Wd\|^2/2.
   \]

   有限模型、λ>0、κ≥0使每个加权模型hθ=θfₚ+(1−θ)fᵣ+R至少λ强凸。epigraph的两个非负乘子和为1，因此θ∈[0,1]足够。非空紧箱及相对Slater条件给出P*=maxθ minᵦ hθ。该凸对偶基础见[Boyd与Vandenberghe](https://web.stanford.edu/~boyd/cvxbook/)；不是本实现独创。空动态箱不适用此推导，记录为输入无可提交范围，不能伪造数值成功。

3. **有效界与相对模型进展。** 箱内步v给U=P(v)。加权模型的强凸下模型给

   \[
   L_\theta=h_\theta(v)+\min_{z\in B}
   [\nabla h_\theta(v)^T(z-v)+\lambda\|z-v\|^2/2]\le P^*.
   \]

   内部最小增量是clip(−∇hθ/λ,ℓ−v,u−v)。保留有效上下界，在P(0)>U且U−L≤η(P(0)−U)时，已取得下降至少是最优正则**局部模型**下降的1/(1+η)。η=.25对应80%，不是命令成功率、非线性收敛率或闭环保证。

   该相对间隙原则明确归于[Zheng、Ma、Xue，TSP 2024，Eq.(23)](https://arxiv.org/html/2304.12522v2#S3)及其§2.3所述前序非精确近端方法；原文相位恢复问题和FISTA实现并不等于当前IK。本实现不移植其收敛定理。单列80%代数推论为原创规则不成立。

SO(3)导数要求旋转对数位于光滑分支；真实问题非线性且受有限预算限制。浮点下界有舍入风险，代码检查非有限与矛盾上下界，并只在已记录舍入容差内处理微小负gap；这不是区间算术证明。正局部阻尼不提供全局非线性收敛、递归可行性或控制稳定性。真正提交的命令仍须通过真实FK和原verifier。

## 与最近方法的具体关系

| 数学／方法基础 | 已有内容 | 本完整实现的具体设计与证据接口 |
|---|---|---|
| [RangedIK，ICRA 2023](https://graphics.cs.wisc.edu/Papers/2023/WPRG23/) | 范围任务、范围内偏好和多任务优化 | 本方法围绕两个范数球的最差利用率，在硬动态箱内联合求步。已有`range_loss_matched`只是范围损失的同合同移植，目标坐标分量、其他运动软项及优化器均不同；它不代表完整RangedIK排名 |
| [Moe等，集合任务IK，2016](https://doi.org/10.3389/frobt.2016.00016) | 按允许集合激活任务，在优先级／零空间结构内安排运动 | 这里没有位置／姿态任务优先级切换，两块通过共同局部模型权衡。集合任务理论不自动成为本有限数值循环的稳定性证明 |
| [Porcelli，非精确有界GN，2013](https://doi.org/10.1007/s11590-011-0430-z)；Zheng等2024 | 有界非精确求解；相对进展停止原则 | 这里优先交付合格命令，尚不能交付时再用可计算界控制同一双块模型的工作量；紧精度／固定1或2次／同外层Clarabel隔离具体覆盖—成本作用 |
| epigraph、活动集、缓存、解析Jacobian | 标准数值组件与实现技术 | 不将任一组件独立列为新优化原理，也不将缓存成本收益全部归于相对停止 |

两个设计部分——双块容差均衡更新、任务验收与模型进展共同控制求解——组成同一个增量数值方法。方法价值必须用同输入合格命令与完整调用成本表达，而非把成熟数学拆成多项原创理论。

## 证据分层与最终叙事边界

| 层次 | 可支持的判断 | 对应范围 |
|---|---|---|
| 数学依据 | 任务集合对应、双块对偶结构、有效界下的局部下降比例 | 以上明确假设；不是新定理或非线性保证 |
| 受控任务证据 | 受限查询中相对固定折中增加少量真实合格命令；相对紧解／固定局部工作量有可测量覆盖—成本作用 | 全样本和全部预定义格同时报告。已观察输入上的最近方法比较，不改称fresh |
| 真实来源回放 | 说明实际请求是否触发额外平衡，以及离线共同输入覆盖／成本 | DROID锁定子集、来源周期、软件合同；不是实机执行、连续闭环TSR或现场发生率 |
| 有限敏感性 | 已观察开发anchors上，五个预声明条件下的数值与任务要求变化 | 不选择新forcing；不是任意容差、机器人或负载的保证 |
| 普通／连续负载 | 旧普通点2000/2000、旧完整轨迹无新增完成、合成扫描不触发额外平衡 | 保留其无增量及不利时限／平滑性事实；不以压力格替代它们 |

最终可写到哪里，由[本轮实测报告](TASK_BALANCE_FINAL_EVIDENCE.md)和旧冻结结果共同决定。当前证据不建立普遍最优、全场景速度优势、闭环续接提升、物理安全、硬实时或完整RangedIK优越性。新增日志只补充适用域证据，不能替代方法原创性判断。
