# Phase 1.5：B2 全变量参照的数值验证

B2是共同工艺域内的构型—时间联合 NLP，不是本项目的新算法，也不是对
Fried–Paternain 双层算法的完整复现。所有96个三次样条系数参与优化，固定首尾，
不选择稀疏块、不使用未来候选方法。每次从保存的同一B1可行路径开始。

## 三个独立校准问题

校准CAD中心 `[0.485,0.005,0.265] m`、偏航7.5°，不同于24个比较场景。
三个Panda平面/柱面/鞍面参考由独立候选构造生成。在其冗余零空间中加入固定
0.22 rad、四周期的关节摆动，再用非线性投影保持原工具位姿，构造较慢但可行
的输入。原无摆动路径仅是已知较快的离线检查参照，**不传给B2作为种子或答案**。
初始、已知较快和采用路径均经过密集几何检查、共同定时及真实力矩执行。

|校准问题|较慢输入计划时间/s|已知较快参照/s|采用的非初始路径/s|结论|
|---|---:|---:|---:|---|
|平面|19.435180|19.421907|18.089187|新的完整验证 incumbent；执行与扫描质量通过|
|柱面|26.348819|26.107939|18.265930|新的完整验证 incumbent；执行与扫描质量通过|
|鞍面|20.216124|19.945464|18.335461|新的完整验证 incumbent；执行与扫描质量通过|

这些是校准能力检查，不是24场景性能结果。三项均实际执行更快，实际时间和
已知较快参照见 `reports/b2_calibration.csv`。不得将该参照当作全局最优。

构造强度需限定：已知参照相对初值只快约0.07%、0.91%、1.34%，尤其平面
不能称“人为明显变慢”的强退化对照。B2实际采用路径相对初值的改善更大，
但这是求解结果，不能倒用它来夸大预先已知参照的差距。本轮因此完成了数值
导数、非初始改善及物理验收检查，却没有充分构造三个均明显劣于预先已知路径
的强压力校准问题；保留此校准设计限制，不隐藏或据此追加样本。

## 排除的实现问题

初始 limited-memory 数值实现仅在柱面校准找到很小改进，在其他两项没有完整
可行新解；所有旧尝试保留在 `b2_calibration_limited_memory/`。
最终实现保持原联合目标和约束，完成以下数值处理：

- 系数增量以0.15 rad无量纲化；`x=s_dot²`以初始周期时间平方倒数无量纲化。
- 用`u=(x[i+1]−x[i])/(2Δs)`精确消去时间离散等式与u变量，首尾x固定为零。
- 移除恒成立的平方量非负下界，避免零梯度冗余约束。
- 使用位置/姿态、速度/加速度和时间目标的解析二阶导数；碰撞距离仍使用
  真实值与解析最近点一阶导数，其二阶项按局部仿射处理，不称完整精确Hessian。
- B2共同离散网格为201均匀点并全部工艺接点和样条节点，所有变量均保留；
  最终3201几何点和6401定时点的独立密集检查不减少。

方向有限差分检查：目标误差不超过2.66e−10，约束尺度归一化误差不超过
5.77e−8。Coal回调没有二阶接口，初次直接对含回调的总图求二阶导数会报接口错误；
随后显式分离可解析曲率，未将该异常计为求解器性能结果。

每个候选都独立复算优化器目标与约束残差，只有全工艺域、碰撞、关节与定时
复核通过的结果才加入incumbent。时间目标同时报告联合变量提议和共同TOPPRA
重定时后的值；实际采用依据后者。优化返回码不能替代这条链。

## 检查点与费用

1/5/10/30秒记录当时**已经完成**全部复核的最好路径，不倒填晚完成的结果。
校准的第一次密集检查约1.8秒，因此1秒记录为缺失而不是零成本成功。
三个问题在10秒前均已有非初始合格改进；上表列30秒内最好路径。
开发主路径固定取10秒检查点，完整运行30秒以保存其他检查点；全部构图、
求解、回调、密集检查和共同重定时计入规划时间。B2还计入获取B1共同初值的成本。

通过这三项仅证明数值参照能够真实改变并改善已知可改进的输入，不保证每个
开发场景都改善，也不保证局部最优或全局最优。开发结果另见Phase1.5报告。

原始文件：`b2_calibration/<family>/optimization.json.gz`、`construction.json`、
`initial_slow.npz`、`known_faster.npz`、`initial/`、`known_faster/`、`adopted/`。
后三级目录包含1ms真实状态、力矩、射线、指标和完整路径。
